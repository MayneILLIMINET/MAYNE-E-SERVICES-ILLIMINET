Pour bouton gris qui refuse de s'activer. Ce fichier tente tous les déblocages logiciels possibles.

ETAPE 2 - Fix sans PC (à faire à la main - 2 min)

  1. Paramètres > Apps > Voir toutes les apps > 3 points > Afficher système > Bluetooth > Stockage > Vider cache + Effacer données
  2. Pareil pour Bluetooth MIDI Service et com.android.bluetooth
  3. Paramètres > Système > Options de réinitialisation > Réinitialiser Wi-Fi, données mobiles et Bluetooth (ça ne supprime pas tes fichiers)
  4. Redémarre en mode sans échec : appuie long sur bouton éteindre > appui long sur "Éteindre" > Mode sans échec > teste Bluetooth. Si ça marche en mode sans échec = une app bloque.

ETAPE 3 - Fix FORCE avec PC (méthode qui débloque 90% des boutons gris)

Il te faut un PC + câble USB :

1. Active Développeur : Paramètres > À propos > tape 7x sur Numéro de build 2. Paramètres > Système > Options développeur > Active Débogage USB 3. Branche au PC 4. Sur PC, installe ADB (tape sur Google "platform tools download") 5. Ouvre CMD / Terminal dans le dossier platform-tools et tape : adb devices adb shell svc bluetooth enable adb shell svc bluetooth disable adb shell svc bluetooth enable 6. Si ça reste gris, tape ça aussi : adb shell pm clear com.android.bluetooth adb shell settings put global bluetooth_on 1 adb reboot

ETAPE 4 - Si toujours gris = hardware

Si après tout ça le bouton reste gris, c'est la puce Bluetooth qui a grillé (choc, eau, mise à jour). Solution : clé USB Bluetooth OTG à 3.000F ou réparation.

Code Android pour forcer (si tu fais une app)

BluetoothAdapter adapter = BluetoothAdapter.getDefaultAdapter(); if (adapter != null) { adapter.enable(); try { Method m = adapter.getClass().getMethod("enable"); m.invoke(adapter); } catch (Exception e) { e.printStackTrace(); } }
